# Pi Rollups medal artwork

The current ribbon medals were supplied by the project owner. The artwork is used as provided, resized to 256 × 256 and encoded as WebP for the website. The source images have opaque black backgrounds; CSS lighten blending integrates them with the dark interface.

## Files

- bronze.webp — green ribbon, Bronze at 1 win
- silver.webp — blue ribbon, Silver at 5 wins
- gold.webp — orange ribbon, Gold at 10 wins
- platinum.webp — teal ribbon, Platinum at 30 wins
- chaos.webp — red ribbon and star-shaped Chaos honor, with a cumulative victory count

The two supplied gold images were identical, so one is used. Previous generated designs and their prompts remain available in Git history.
